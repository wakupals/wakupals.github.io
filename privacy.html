プライバシーポリシー

最終更新日：2026年11月12日

わくパル（以下「本アプリ」といいます。）の運営者（以下「運営者」といいます。）は、本アプリにおけるユーザーの情報の取扱いについて、以下のとおりプライバシーポリシーを定めます。

1. 基本的な考え方

本アプリは、アカウントの登録やログインをしなくても利用できます。初めて起動したとき（アップデート後の1回目を含みます）に、アカウントの登録・ログイン（メールアドレスとパスワード、または Apple）をするか、登録せずに使うかを選ぶ画面が出ます。どちらを選んでも、端末の中のデータは消えません。ログインしない場合は、端末ごとのランダムな匿名の ID（名前・メールアドレス・Apple ID とは結び付いていません）が自動で作られます。

こつこつ（集中）の記録のメモ、写真、設定などのデータは、ユーザーの端末の中に保存されます。ただし、ダイヤを正しく管理するため、一部の情報を運営者のサーバーに送ります。また、ユーザーがアカウントの登録・ログインをした場合（任意です）は、端末の中のデータ（写真を除く）も自動で運営者のサーバーに保存します（いずれも第3項）。

ユーザーが自分からお問い合わせを送信したときだけ、その内容が運営者に届きます（第4項）。

ユーザーが「みんなでこつこつ」の部屋に入っているあいだだけ、同じ部屋の人に見せるための最小限の情報を、リアルタイム通信サービスを通じて送ります（第5項）。

2. 端末の中にだけ保存される情報

本アプリは、次の情報をユーザーの端末の中に保存します。第3項に書いたもの以外が運営者に送信されることはありません。

  • こつこつ（集中）した時間の記録と、入力したメモ
  • パルの名前やプロフィールなど、ユーザーが入力した内容
  • ログインボーナスの受け取り状況、パルとのなかよし度などの進み具合（ダイヤの残高と解放したアイテムは、第3項のとおりサーバーでも管理します）
  • こつこつのあとに「アルバムに残す」を押して残した記念写真（アルバム）と、そこに書いたコメント
  • BGM やテーマの色などの設定

記念写真には、そのときのパルの姿・背景・日付・こつこつした時間と、ユーザーが書いたコメントが入ります。「みんなでこつこつ」の回は、同じ部屋にいた人のパルの種類も写ります（その人の名前や ID は入りません）。

記念写真は端末の中にだけ保存され、運営者や同じ部屋の人に送られることはありません。ユーザーが「画像を保存」を押したときだけ端末の「写真」アプリに追加し、「共有」を押したときだけ、ユーザーが選んだアプリに画像を渡します。「写真」への追加の許可は追加のためだけに使い、本アプリが端末の写真を読み取ることはありません。

本アプリを削除すると、これらの情報も端末から削除されます（サーバーに保存された情報は第3項、第8項をご覧ください）。

3. ダイヤの管理（運営者のサーバーに保存する情報）

ダイヤの残高、購入、返金を正しく管理し、記録の水増しなどの不正を防ぐため、運営者は、Supabase, Inc. が提供するサービス（データベースと匿名ログイン）の上に、ダイヤを管理するサーバーを置いています。次の情報がこのサーバーに送られ、保存されます。

  • 端末ごとにアプリが自動で作る匿名の ID
  • こつこつの記録のうち、ダイヤの計算に必要な部分（記録の ID、始めた時刻と終えた時刻、集中した秒数、最後までやりきったかどうか）。入力したメモ、「やること」、写真、パルの名前は送りません
  • ログインボーナスを受け取った日付と何日目か、広告ボーナスを受け取った記録
  • ダイヤで解放した背景・アクセサリー・アイテムの ID と、使ったダイヤの数
  • ダイヤの増えた・減った履歴（いつ、何の理由で、いくつ）
  • ダイヤを購入したときの取引の情報（App Store の取引 ID、商品、購入日時、個数、Apple が発行した取引の署名データ）
  • 以前の版で端末に貯まっていた記録を、サーバーに引き継ぐとき（初めの1回）に送る、その時点までの上記の情報

クレジットカードなどの支払い情報は、Apple が処理し、運営者には届きません。

利用目的は、ダイヤの残高・購入・返金の管理、不正の防止、お問い合わせへの対応です。広告や分析には使いません。

サーバーとの通信は、アプリを開いたとき、記録が増えたとき、ダイヤを使うまたは購入したときなどに行われます。通信できないときは、あとで送ります。Supabase は、通信の運用のために、IP アドレスなどの接続の記録を一定期間保持することがあります（Supabase の取扱いは第5項のリンクをご覧ください）。

匿名の ID は、端末の中のアプリのデータとして保存されます。アカウントの登録・ログインをしていない場合、本アプリを削除したり、機種変更をしたりすると、この ID が失われ、購入したダイヤを含む残高を引き継げません（運営者も復元できません）。

アカウントの登録・ログインをしたとき（任意。初めて起動したときの画面か、設定の「データの保存」で選べます）

アカウントは、メールアドレスとパスワード、または「Apple でログイン」で登録できます。どちらも、それまでの匿名の ID にそのままつながるので、ダイヤの残高や購入の記録も引き継がれます。機種変更や入れ直しのときに、同じ方法でログインすると引き継げます。

メールアドレスで登録した場合は、メールアドレスと、パスワード（Supabase が元に戻せない形に変換して保存するので、運営者も元のパスワードを見ることはできません）を保存します。メールアドレスは、登録の確認メールとパスワードの再設定メールを送るため、およびお問い合わせへの対応のためにだけ使い、広告やお知らせの配信には使いません。これらのメールは、Supabase から、運営者の Gmail のアカウント（Google LLC のメールサービス）を使って送られます。そのため、宛先のメールアドレスとメールの内容は Google を経由します（Google の取扱いは第6項のリンクをご覧ください）。

「Apple でログイン」を選んだ場合は、お名前とメールアドレスは求めません。保存するのは、Apple がこのアプリ用に発行する識別子です。ダイヤの残高や購入の記録は、そのままつながります。機種変更や入れ直しのときに、同じ Apple でログインすると引き継げます。

ログインしているあいだは、端末の中のデータを、自動で運営者のサーバーにも保存します（ログアウトすると、自動の保存は止まります）。匿名のままの場合は、この保存は行われません。保存するのは次のものです。

  • こつこつの記録（入力したメモ、「やること」を含む）
  • パルの名前や一言など、ユーザーが入力した内容
  • ログインボーナス、広告ボーナスの受け取りの記録
  • 解放した背景・アクセサリー・きせかえと、いまの選択
  • パルとのなかよし度と、アルバムの記録（コメントなどの文字。写真の画像データそのものは含みません）
  • BGM やテーマの色などの設定

「みんなでこつこつ」の部屋に関する情報（部屋で使う ID、部屋の履歴、非表示にした人など）は、保存しません。

ログインしたデータは、機種変更などのときに戻せるようにするためだけに使います。

設定の「データの保存」からログアウトすると、自動の保存は止まります。設定画面の「アカウントを削除」を押すと、サーバーに保存した上記のすべての情報（匿名の ID、ダイヤの残高、購入の記録、預けたデータ）が削除されます。端末の中のデータは消えません。Apple の側に残る購入の履歴や、Supabase が一定期間保持する接続の記録は、削除されません。

4. お問い合わせのときに運営者が受け取る情報

アプリ内のお問い合わせ画面から送信された内容は、フォームの配信サービス「Formspree」（Formspree, Inc.／米国）を通じて、運営者のメールアドレスに届きます。その際、運営者は次の情報を受け取ります。

  • お問い合わせの内容と、選択された種別
  • 返信先として入力されたメールアドレス（入力された場合のみ）
  • アプリのバージョンと、端末・OS の情報（不具合を調べるために自動で添えられます）

これらの情報は、お問い合わせへの回答と不具合の調査のためにだけ利用します。

Formspree は、送信された内容を運営者へ転送し、運営者の管理画面に保存します。Formspree の取扱いについては、同社のプライバシーポリシー（https://formspree.io/legal/privacy-policy/）をご覧ください。

通信の状態などで送信できなかった場合は、ユーザーの端末のメールアプリから送信する方法に切り替わります。その場合は、Formspree を経由せず、送信元のメールアドレスを運営者が受け取ります。

5. みんなでこつこつ（同じ部屋の人に見える情報）

「みんなでこつこつ」は、大切な人（部屋コード）や知らない人と同じ部屋に入り、おたがいがこつこつしている様子を見られる機能です。部屋に入ったとき、部屋を出るまでのあいだだけ、次の情報を同じ部屋の人に送ります。

  • 端末ごとにアプリが作るランダムな ID（個人の名前や Apple ID とは結び付いていません）
  • 選んでいるパルの種類と、使っている背景
  • いまの状態（こつこつ中・休憩中・じゅんび中）と、こつこつを始めた時刻
  • 「大切な人と」の部屋に限り、ユーザーが自分で入力した「やること」（1〜2件・各30文字まで）
  • 「大切な人と」の部屋を招待コードを表示してつくった場合に限り、ユーザーがつけた「部屋の名前」（20文字まで）
  • ユーザーがパルに自分でつけた名前（6文字まで。「大切な人と」「みんなで」のどちらの部屋でも送ります。名前をつけていない場合は送りません）

ユーザーの名前、記録の内容、位置情報は送りません。「パルにつけた名前」は、どちらの部屋でも同じ部屋の人に見えます。「やること」「部屋の名前」は「大切な人と」の部屋でだけ同じ部屋の人に見えます（「みんなで」の部屋には送りません）。この3つ以外に、文字や写真を送りあう機能はありません。

この通信には、Supabase, Inc. が提供するリアルタイム通信サービス「Supabase Realtime」を利用しています。運営者は、これらの情報を保存せず（第3項のダイヤの管理用のデータとは別です）、部屋を出る（またはアプリを閉じる）と、部屋からその情報は消えます。ただし、Supabase は通信の運用のために、IP アドレスなどの接続の記録を一定期間保持することがあります。Supabase の取扱いについては、同社のプライバシーポリシー（https://supabase.com/privacy）をご覧ください。

「みんなで」の部屋には、同じ時間にその部屋に入った不特定の人が入ります。「大切な人と」の部屋は、部屋コードを知っている人なら誰でも入れます。部屋コードは、信頼できる人にだけ伝えてください。

どちらの部屋でも、他の人の「パルにつけた名前」「やること」「部屋の名前」がふさわしくないと感じたときは、その人のマスの「…」から、運営者に通報する（通報の内容は運営者にだけ届き、相手には伝わりません）か、その人を非表示にすることができます。非表示にした人の情報は、この端末の中にだけ保存されます。

「みんなでこつこつ」の部屋に入らなければ、上記の情報を部屋に送る通信は行われません。

アプリのホーム画面では、「いま〇人」を表示するため、数秒だけ同じサービスに接続して、いまこつこつしている人数を数えます。このとき送られるのは接続に必要な情報だけで、ユーザーの状態は部屋に入っていなければ送られません。

6. 広告について

本アプリは、Google LLC が提供する広告配信サービス「Google AdMob」を利用しています。広告は、ユーザーが「広告を見て」のボタンを押したときにだけ表示されます（リワード広告）。広告を見なくても、本アプリのすべての機能を利用できます。

広告の配信にあたって、Google は次の情報を取得することがあります。

  • 端末の識別子（広告主向け識別子 IDFA を除く）
  • IP アドレスと、そこから推定されるおおまかな地域
  • 広告の表示や操作の履歴
  • 動作状況や不具合に関する診断情報

本アプリは、App Tracking Transparency による許可を求めていません。そのため、広告主向け識別子（IDFA）を使ったトラッキング（他社のアプリやウェブサイトをまたいだ追跡）は行いません。

欧州経済領域（EEA）、英国、スイスのユーザーには、Google の同意フォームで広告に関する同意を確認します。

Google による情報の取扱いについては、次のページをご覧ください。

  • Google プライバシーポリシー：https://policies.google.com/privacy
  • Google のサービスを使用するサイトやアプリから収集した情報の Google による使用：https://policies.google.com/technologies/partner-sites

7. 第三者への提供

運営者は、法令に基づく場合を除き、お問い合わせやダイヤの管理で受け取った情報を、ご本人の同意なく第三者に提供しません。

お問い合わせの送信と転送のために、第4項のとおり Formspree を利用します。

「みんなでこつこつ」の通信と、ダイヤの管理・データの保存のために、第5項・第3項のとおり Supabase を利用します。

「Apple でログイン」を選んだ場合は、Apple のサービスを利用します。メールアドレスで登録した場合の確認メール・再設定メールの送信には、第3項のとおり Supabase と Google（Gmail）を利用します。

ダイヤの購入は Apple（App Store）が処理します。運営者は、第3項に書いた取引の情報を受け取ります。

広告の配信に必要な情報は、第6項のとおり Google が直接取得します。

8. 情報の削除

端末の中に保存された情報は、本アプリを削除することで削除できます。

サーバーに保存された情報（第3項）は、本アプリを削除しても残ります。設定画面の「アカウントを削除」から、いつでもご自身で削除できます。端末から削除できない場合や、お問い合わせで運営者が受け取った情報の削除をご希望の場合は、下記のお問い合わせ先までご連絡ください。サーバーの情報は匿名の ID で管理しているため、ご本人のものと確認できる情報（購入の取引の記録など）をお知らせいただくことがあります。法令により保存が必要なものを除き、確認できた情報を削除します。

9. アプリ内課金について

本アプリでは、ダイヤを App Store のアプリ内課金（消耗型）で購入できます。価格は購入画面に表示されます。購入しなくても、ダイヤは本アプリを使うことで獲得できます。

お支払いは Apple が処理します。返金は Apple の定めに従います。返金が行われたときは、購入したぶんのダイヤを残高から差し引きます（すでに使っていて残高が足りないときは、差し引ける分だけです）。

購入の取引の情報の取扱いは、第3項をご覧ください。

10. お子様の利用について

13歳未満の方は、保護者の方の同意を得たうえでご利用ください。

11. このポリシーの変更

本ポリシーは、法令の改正や本アプリの内容の変更に応じて改定することがあります。

変更後の内容は、本アプリ内または運営者の公開ページに掲載した時点から効力を生じます。
